Backend orchestration

      

        
1. Local insurance rating
basePremium = rate% × declaredValue × (dur/12). stampDuty = subTotal × 5%. govtLevy = RTAbaseline × 12% × (dur/12). No IceCash call.

        
2. TPILICQuote (batched, conditional)
If bundleLicence or bundleRadio true. Response includes: Licence.ArrearsAmt, Licence.PenaltiesAmt, Licence.LicExpiryDate, Licence.TotalLicAmt, Licence.TotalRadioTVAmt — all surfaced on the quote screen. RadioTVUsage derived from VehicleType (private→1, commercial→2) or overridden to 3 when TV toggle on.

        
3. Merge and return
Local insurance + IceCash licence/radio consolidated. PARTIAL if any UNAVAILABLE. validUntil: +48 hours.

        
4. EcoCash initiation
Idempotency guard. USSD push. Portal polls GET /status every 5s, max 10.

        
5. EcoCash callback
IP-allowlisted. HTTP 200 within 5s. Dispatches: ReceiptPDFJob, SMSJob, ProcessIceCashApprovalJob.

        
6. TPILICUpdate
PaymentMethod: 3, DeliveryMethod: 2, LicenceCert: 0, InsuranceCompanyID: 24, LocationID: [OI-001].

        
7. TPILICResult polling
Returns CombinedID, LicenceID, InsuranceID, PolicyNumber, ReceiptID, confirmed dates.

        
8. QueuePolicyIssuanceJob → PURE
digitalPolicyNumber immediate; corePolicyNumber async.

        
9. Document generation
Cover note: VRN, Make/Model, InsuranceType, dates, PolicyNumber, ReceiptID. DocumentsReady → email.
